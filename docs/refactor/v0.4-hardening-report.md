# AIO-Gym 0.4 post-refactor hardening report

Date: 2026-08-07

## Scope and outcome

This release keeps the five-package Scenario -> PlantConfig ->
OperatingCondition -> TaskSpec -> Environment architecture and closes six
identity or semantics gaps:

1. Plant, Condition, Task objective, and resolved-plant mappings are deeply
   immutable; declared hashes are validated.
2. Engineering studies share one explicit resolved Condition across static,
   steady, dynamic, safety, robustness, and sweep paths.
3. Parameterized three-tank public actions contain only installed actuators.
4. Evaluation and collection share one strict policy-target contract resolver.
5. Scheduled events are applied before the corresponding policy action and
   Dataset v4 records transition and next-observation contexts.
6. The economic Task uses dimensional rates integrated over `control_dt`, with
   coefficients included in Task identity.

## Intentional compatibility changes

- package version: 0.4.0;
- Dataset: v4 with `pre-action-v1` semantics;
- evaluation result schema: v2;
- economic Task: revision 2, `net-economic-value-v2`, `economic-core-v2`;
- custom equipment layout changes alter Plant and interface hashes;
- old economic and mismatched-interface checkpoints are rejected;
- the CasADi extra is `symbolic`; unimplemented ONNX/HPO extras are removed.

## Validation

Final command results, distribution checksums, optional-dependency coverage,
and remaining limitations are added after the release verification phase.
